## Naming conventions in this skill

- Rule IDs are stable across releases: `W-*` worldbuilding, `D-*` system design, `P-*` dialogue patterns, `Q-*` Q&A insights, `A-*` anti-patterns.
- Diagnoses must cite a rule ID. If a finding has no rule yet, add one to the matching reference rather than inventing an ID in the answer.
- Do not translate proper nouns from the source game inconsistently. When in doubt, use the English term once and keep it.
